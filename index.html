    Silme hakkında: silinen kullanıcı bir daha giriş yapamaz. Ancak daha önce indirdiği şifreli kopyayı eski şifresiyle açabilir; bunu da kesmek için bilgisayarda yayinla.py --yeni-anahtar ile veri anahtarı yenilenmelidir.

    Bağlı değil

    Erişim anahtarı

    Şifre ve kullanıcı değişiklikleri yayın deposundaki kasa.json dosyasına bu anahtarla kaydedilir. Anahtar yalnız bu tarayıcıda kalır ve yalnız GitHub'a gönderilir.

    Anahtar nasıl alınır?

    1. GitHub'da yeni fine-grained token sayfasını açın.
    2. Repository access → Only select repositories → yalnız Ulema-Ravi-Detay-Site.
    3. Permissions → Contents → Read and write. Başka izin gerekmez.
    4. Oluşan anahtarı yukarıdaki alana yapıştırıp Kaydet ve bağlan'a basın.

    Anahtarsız kullanım

    Anahtar girilmezse değişiklik yapıldığında güncel kasa.json indirilir; dosyayı yayın deposuna Add file → Upload files ile yüklemeniz gerekir.
